# FairShare for Android

This repository only hosts the **FairShare Android app** for download.

**Get the app:** https://fairshare-sonu.web.app/download

Latest APK: https://github.com/spiderim/fairshare-app/releases/latest/download/FairShare.apk

To install, open the downloaded `FairShare.apk` on your phone and allow your browser to install apps if Android asks.
